# androsaur-hub

Домашний сервер Androsaur: админка для телефонов-ассистентов. Здесь задаются настройки,
которые телефоны забирают сами, и видно, какие телефоны на связи и применили ли они настройки.
Позже здесь появятся вход, прослушивание голосовых записок, роли, имена и синхронизация лиц.

Стек: Python 3.11+, FastAPI, Jinja2, SQLite, pytest, ruff, mypy (strict).

## Сейчас

- Страница «Настройки дома» (`/`): значения, которые телефон описал сам (первая —
  «Затемнение экрана, когда никого нет», по умолчанию 30 с), сохранение и сброс на умолчание.
- Список устройств: на связи или нет, давность последнего обращения, применена ли последняя
  ревизия настроек.
- Страница «Люди» (`/people`): люди дома — их узнают все телефоны. Хаб хранит постоянный ID,
  имя и наборы чисел лица (до 60 на человека, без фотографий; в админке только число наборов).
  - Первый телефон, пока в доме никого нет, приносит своих людей.
  - Чистый телефон сразу получает всех и узнаёт без обучения.
  - Люди телефона, обученного в другой системе, попадают в «Новые с телефонов»: объединить с
    человеком дома (наборы складываются, записки на телефоне переходят к нему) или добавить.
  - Чему учится принятый телефон, уходит в хаб и раздаётся остальным.
  - Переименование меняет только имя; записки привязаны к ID и остаются за человеком.
- Раздел «Погода» на странице настроек: город для всего дома (поиск — Nominatim, © OpenStreetMap). Хаб обновляет прогноз
  MET Norway в фоне (не чаще раза в 30 минут и не раньше срока, который просит MET) и отдаёт его телефонам в `sync`
  (`weatherPlace`, `weather`). Город не задан — каждый телефон показывает погоду там, где стоит. Телефоны без хаба берут
  погоду сами. Прогноз Open-Meteo из домашней сети недоступен, а его поиск не находит многие русские названия.
- API для телефона: `POST /api/device/register` (о себе и схема настроек), `POST /api/device/sync`
  (применённая ревизия, люди камеры с отпечатками наборов, результаты команд → настройки, команды,
  `peopleRev` и `upload` — чьи наборы прислать), `POST /api/device/people/upload` и
  `POST /api/device/people/download` (люди дома с наборами).

Телефон ходит к хабу по домашнему Wi‑Fi. Входа пока нет: хаб доступен всем в домашней сети, наружу его не открывать.
Наборы чисел лица (биометрия) сейчас может скачать любое устройство в домашней сети, назвавшись телефоном, — вход и
токены устройств нужны до того, как хаб окажется где-то кроме домашней сети.

## Запуск в домашней сети

```bash
uv run uvicorn app.main:app --host 0.0.0.0 --port 8770
# телефону один раз передать адрес хаба в домашнем Wi‑Fi (адрес компьютера с хабом):
adb shell am start -n dev.hram.androsaur/.MainActivity --es hub http://<адрес хаба>:8770
# админка: http://<адрес хаба>:8770
```

Адрес хаба телефон запоминает; пустое значение (`--es hub ""`) отключает хаб.

## Команды

```bash
make install     # pip install -e ".[dev]"
make dev         # uvicorn --reload
make check       # ruff + mypy + pytest
```

## Конфигурация

Переменные с префиксом `HUB_` (см. `app/config.py` и `.env.example`): `HUB_APP_NAME`,
`HUB_DEBUG`, `HUB_DATABASE_PATH` (по умолчанию `data/hub.sqlite3`), `HUB_HOST`, `HUB_PORT`,
`HUB_ONLINE_WINDOW_S` (сколько секунд после последнего обращения устройство считается на связи).
